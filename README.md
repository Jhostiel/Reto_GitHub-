# Mi primer proyecto con Git y GitHub

## Descripción

Este repositorio documenta mi proceso de aprendizaje y práctica del control de versiones con Git y GitHub, mediante ejercicios que permiten comprender y aplicar sus principales funcionalidades.

## Contenido

Durante el desarrollo de este proyecto se trabajan los siguientes temas:

- Creación y administración de repositorios.
- Seguimiento de cambios en archivos.
- Registro de versiones mediante commits.
- Trabajo con ramas.
- Comparación e integración de cambios.
- Sincronización entre repositorios locales y remotos.

## Tecnologías y herramientas

- Git
- GitHub
- Markdown
- Terminal de Linux

## Estado del proyecto

Proyecto en desarrollo. Se actualizará progresivamente a medida que avance el aprendizaje y se incorporen nuevos ejercicios prácticos.
